# ukragro-prices
Автоматичне об’єднання щоденних цін UkrAgroConsult.

## Як запустити
- **GitHub:** Actions → «Оновити загальний Excel» → Run workflow. Готовий файл — в Artifacts запуску.
  Галочка «full_rebuild» перечитує всі файли з `input/` з нуля.
- **Локально:** `pip install -r requirements.txt`, потім `python build_master.py`
  (або `python build_master.py --full-rebuild`).

## Що де лежить
| Шлях | Призначення |
|---|---|
| `input/` | Щоденні Excel-файли UkrAgroConsult (аркуші `ДД.ММ.РРРР_min_max`). |
| `data/prices_db.csv` | Накопичена база всіх цін. Оновлюється й комітиться після кожного запуску. |
| `data/processed_files.csv` | Які файли вже в базі (назва + SHA256). Незмінені файли повторно не читаються. |
| `output/UKRAGRO_ALL_PRICES.xlsx` | Результат. |

Старі файли з `input/` можна прибирати — їхні дані лишаються в `data/prices_db.csv`.
Після `--full-rebuild` база будується лише з того, що зараз лежить в `input/`.

## Логіка аналітичних аркушів
- **Місяць поставки не зашитий.** На кожну дату береться найближчий доступний місяць поставки
  (минулі місяці — в останню чергу). Для спредів, премій і порівняння з конкурентами береться
  *спільний* для всіх серій блоку місяць, щоб не віднімати липень від серпня.
- Колонка «Поставка (остання дата)» показує, який контракт використано. Комірка з червоним шрифтом
  і приміткою — дата, коли серія перейшла на наступний місяць поставки (стрибок ціни може бути
  наслідком переходу, а не ринку).

## Якщо змінився формат вхідних файлів
Усі налаштування — на початку `build_master.py`:
- `HEADER_ALIASES` — варіанти заголовків колонок (російські й англійські: `товар`/`Commodity`,
  `базис`/`Delivery terms` …). Новий варіант — просто дописати в список.
- `ODESA`, `BLACK_SEA_PORTS`, `WESTERN_BORDER` … — синоніми портів
  (напр. `Chornomorsk` у 2024 і `Chornomorsk, Odesa, Pivdennyi` з 2025). Порядок портів через кому не важливий.
- `COMMODITY_TYPE_FALLBACK` — категорія товару, якщо у файлі немає колонки «тип товару».

## Перевірки
- Аркуш, у якого дата в колонці Date не збігається з назвою (копія попереднього дня), **не включається** в базу.
- Аркуш із цінами, ідентичними іншій даті, включається, але з попередженням.
- Усе це, а також покриття кожної аналітичної серії, — на аркуші **«Контроль якості»** і в підсумку запуску на GitHub.
- Якщо хоч один аркуш не прочитано (статус «Помилка»), Excel і база все одно зберігаються,
  але запуск на GitHub позначається червоним.
